### `projeto-concessionaria/`
Projeto prático desenvolvido para a disciplina de **Programação Orientada a Objetos** na UniFECAF.

Sistema CRUD de gestão de estoque de veículos, com as seguintes funcionalidades:
- Cadastro, consulta, atualização e remoção de **marcas**, **modelos** e **veículos**
- Filtros por marca, modelo, preço, ano e status
- Arquitetura **MVC** (Model-View-Controller)
- Interface via terminal (CLI)

**Tecnologias:** Java • MySQL • JDBC

#### Como rodar o projeto
1. Instale o MySQL e execute o script `src/com/projeto/database/model.sql`
2. Ajuste usuário e senha em `Conexao.java`
3. Adicione o `mysql-connector-java-8.0.25.jar` como dependência no projeto
4. Execute `App.java`
